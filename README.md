# CRM Leads Sol Nascente Motos

Mini CRM de captação e gestão de leads para a Sol Nascente Motos (concessionária Honda — unidades Teresina e Timon).

> 🚧 Em desenvolvimento — teste técnico de recrutamento.

## Rodar localmente

```bash
cp .env.example .env
docker compose up --build
```

App em `http://localhost:3000`.
